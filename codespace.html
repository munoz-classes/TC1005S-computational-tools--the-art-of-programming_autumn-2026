Cómo abrir tu Terminal Linux (Codespaces) y tu Simulador (Wokwi) en 60 segundos

En esta Semana Tec trabajaremos directamente en la nube para que todas las computadoras tengan exactamente las mismas herramientas preinstaladas (Unix, Bash, Git, Compilador C/Python y Simulador de Hardware).

1️⃣ Parte A: Tu Terminal Unix y Editor de Código (GitHub Codespaces)

  1. Inicia sesión en https://github.com y haz clic en el botón verde New (Nuevo repositorio).
  2. ⚠️ ¡MUY IMPORTANTE! En la casilla Owner (Propietario), asegúrate de que esté seleccionado tu propio nombre de usuario personal (no una organización) para activar tus 60 horas gratuitas.
  3. Nombra tu repositorio semana-tec-mision, elígelo como Public, marca la casilla Add a README file y haz clic en Create repository.
  4. Dentro de tu repositorio, haz clic en el botón verde <> Code → cambia a la pestaña Codespaces → haz clic en Create codespace on main.
  5. En 15 segundos se abrirá Visual Studio Code en tu navegador con tu Terminal de Linux Ubuntu lista en la parte inferior.

💡 Plan B Instantáneo: Si tu cuenta de GitHub presenta algún bloqueo, abre https://shell.cloud.google.com con tu cuenta de Google. Tendrás exactamente el mismo entorno Linux + Terminal + Git al instante.

2️⃣ Parte B: Tu Laboratorio de Cohetes y Robótica (Simulador Wokwi)

  1. Entra a https://wokwi.com e inicia sesión con tu cuenta de Google o GitHub.
  2. Baja a la sección Start from Scratch y selecciona Arduino Uno (o ESP32).
  3. A la izquierda verás el Editor de Código (sketch.ino) y la pestaña diagram.json (donde puedes pegar circuitos completos generados con IA).
  4. A la derecha verás tu tarjeta electrónica: usa el botón morado + para agregar servomotores o luces LED, y el botón verde Play (▶) para compilar y probar en vivo.
  5. Haz clic en Save y luego en Share para copiar el enlace de tu simulación y pegarlo en tus entregas de Canvas/GitHub.

ls -la (Ver todos los archivos, incluidos los ocultos con punto)  |  cd carpeta (Entrar a una carpeta)  |  cd .. (Regresar un nivel atrás)
cat archivo.txt (Leer el contenido de un archivo)  |  grep -rn "PALABRA" . (Buscar texto dentro de cientos de archivos)
find . -name "archivo" (Encontrar un archivo perdido)  |  history > bitacora_lunes.txt (Guardar tu evidencia del Lunes)
